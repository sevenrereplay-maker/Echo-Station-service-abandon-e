## Le projet
Notre projet consiste a crée un décor 3D Low-Ploy représentant une ancienne station-service abandonnée l'ambiance recherchée est une ambiance calme, mystérieuse et marquée par la reprise de la nature sur l’architecture. .

## Ouvrir le projet
Logiciel et version. Fichier à ouvrir en premier.
Cloner avec GitHub Desktop, qui inclut Git LFS : accepter
Initialize Git LFS si la fenêtre s'affiche. En ligne de commande, faire
git lfs install AVANT le clone, sinon les assets arrivent
sous forme de pointeurs de texte et non de fichiers binaires.

## Conventions
Nommage des fichiers : Props,Texures. Convention de commit, mettre une description sur l'avancé de la tâche. Nommage des branches, 2 branches pour les 2 artistes travaillant sur le projet.
